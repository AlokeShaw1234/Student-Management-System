🎓 Student Management System — C++

A console-based Student Management System built with C++ using Object-Oriented Programming principles. The application provides a simple and structured way to manage student records through a menu-driven interface.

🚀 Features : 

- ➕ Add Student — Add new student records.
- 📋 Display Students — View all registered students.
- 🔍 Search Student — Find a student using their roll number.
- ✏️ Update Student — Modify existing student information.
- 🗑️ Delete Student — Remove a student record.
- 📊 Grade Calculation — Automatically assign grades based on marks.
- 🚪 Exit — Safely close the application.

🛠️ Tech Stack Used : 

- Language: C++
- Concepts: Object-Oriented Programming (OOP)
- STL: "vector"
- Programming: Functions, loops, conditional statements, switch-case
- Interface: Command Line
